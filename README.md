# 🗃️ Obsidian Starter Vault

> A vault that teaches you Obsidian *while you use it*. Clone it, open it, live in it.

You downloaded Obsidian. You opened it. You stared at the empty purple void. You closed it.

Sound familiar? This repo is the antidote. It's not a template, not someone's 400-plugin galaxy-brain setup, and not a 2-hour YouTube course. It's a **working vault with the tutorial built in as notes** — because the best way to learn a note-taking app is, shockingly, by taking notes in it.

## 🚀 Getting started (60 seconds, timed)

1. Clone this repo (or click **Code → Download ZIP** and unzip it)
2. Open Obsidian → **Open folder as vault** → pick this folder
3. Open **[[START-HERE]]**
4. That's it. The vault takes over from there.

## 🧭 What's inside

```
📁 00-daily/       ← one note per day. Diary, todos, chaos. All of it.
📁 10-projects/    ← one note per thing you're building
📁 20-ideas/       ← article ideas, app ideas, shower thoughts
📁 30-reference/   ← stuff worth keeping (article notes, how-tos)
📁 templates/      ← pre-made daily/project/idea/review templates
📁 onboarding/     ← the 4-week guided path (the actual tutorial)
📁 tips/           ← one trick per note, snack-sized
📁 ai/             ← point Claude (or any LLM) at your vault
```

The `.obsidian/` config is checked in, so daily notes and templates **work on first open**. No setup screen, no plugin safari.

## 🗓️ The 4-week path

| Week | You learn | Effort |
|------|-----------|--------|
| 1 | The daily note habit | 5 min/day |
| 2 | `[[Linking]]` your brain together | still 5 min/day |
| 3 | Tasks + the only 4 plugins you need | one 15-min setup |
| 4 | The weekly review (where it all compounds) | 10 min/week |

No week 5. After that it's just *your* vault.

## 🤖 The AI part

Your vault is plain markdown, which means any AI tool can read it. The `ai/` folder shows you how to point [Claude Code](https://claude.com/claude-code) at your vault to summarise your week, extract every open todo, or draft an article from an idea note. There's even a `CLAUDE.md` in the repo root that teaches Claude this vault's conventions automatically.

Local-model person? Same trick works with anything that can read a folder of `.md` files.

## 🧘 The philosophy

- **One habit before forty plugins.** The daily note is the keystone. Everything else is optional.
- **Links > folders.** Folders are where notes sleep; links are how they talk.
- **Your vault should survive Obsidian.** Plain markdown, no lock-in, readable in 2050.
