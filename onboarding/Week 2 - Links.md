# Week 2 — Links

**The whole week in one sentence:** whenever you mention a project, person, or idea in your daily note, wrap it in `[[double brackets]]`.

## The magic trick

Type `[[` and start typing a name. If the note exists, link it. If it doesn't, **link it anyway** — Obsidian creates it the moment you click it. Unresolved links aren't errors; they're notes waiting to be born.

So your daily note goes from:

> Worked on the reading app, talked to Sam about the pricing idea.

to:

> Worked on [[Reading App]], talked to Sam about [[Pricing Idea]].

## Why bother

Open [[Example Project]] and look at the **Backlinks** panel (right sidebar). Every daily note that ever mentioned it is listed there — a free, automatic project log you never had to maintain. That's the entire Obsidian value proposition in one panel: *folders are where notes sleep; links are how they talk.*

## This week's habits

1. Keep the daily note streak going
2. Add 2–3 `[[links]]` per daily note
3. When you have a real idea, create it properly: `Ctrl/Cmd + P` → **"Templates: Insert template"** → [[idea]] (see the example in `20-ideas/`)

## Party trick

`Ctrl/Cmd + P` → **"Graph view: Open graph view"**. Mostly useless, extremely motivating. Watch it grow.
