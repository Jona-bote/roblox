# Week 3 — Tasks and Plugins

**The whole week in one sentence:** you've earned plugins now — install exactly four.

## First, tasks (no plugin needed yet)

You've been writing `- [ ]` todos in daily notes. The problem: they're scattered across 14 files. The fix is below, but know that even scattered, they're searchable: search for `- [ ]` (or use the query `task-todo:""` in search) and every open todo in your vault appears.

## The only four plugins you need

**Settings → Community plugins → Turn on community plugins → Browse.** Install these, in this order (details in [[Recommended plugins]]):

1. **Calendar** — a month view in the sidebar; click any day to open that daily note. Instantly makes the diary habit feel real.
2. **Tasks** — supercharges checkboxes: due dates, recurring tasks, and one query block that gathers every open todo from the whole vault into a single view.
3. **Templater** — templates with superpowers (auto-dates, cursor placement). Your existing templates keep working; upgrade them when you feel the itch.
4. **Dataview** — turns notes into a database. "Show me all ideas with `status: seed`" becomes a three-line query. Save this one for last; it's the deep end.

## Make yourself a todo dashboard

Create a note called `Todo Dashboard` in the vault root and paste:

````
```tasks
not done
```
````

Open it. Every unfinished todo you've ever written, one page. This note alone converts most sceptics.

## What NOT to do

- ❌ Install a fifth plugin. You will be tempted. The plugin browser is a casino. Walk away.
