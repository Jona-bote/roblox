# Recommended plugins

The blessed four (install in [[Week 3 - Tasks and Plugins]]), plus a "later, maybe" shelf.

## The core four

| Plugin | What it does | Why it made the cut |
|--------|--------------|---------------------|
| **Calendar** | Month view in sidebar; click a day → that daily note | Makes the diary habit tangible |
| **Tasks** | Due dates, recurrence, vault-wide todo queries | One dashboard for every `- [ ]` you ever write |
| **Templater** | Templates with logic, prompts, auto-dates | The core Templates plugin, but grown up |
| **Dataview** | Query notes like a database | Turns frontmatter (`status: seed`) into live lists |

## Later, maybe (only when you feel a specific pain)

- **Periodic Notes** — weekly/monthly notes with the same one-command flow as dailies
- **Kanban** — project boards as markdown files
- **Excalidraw** — sketching and diagrams inside notes
- **Obsidian Git** — auto-backup your vault to a git repo
- **Smart Connections / Copilot** — AI over your notes (see [[Use Claude Code on this vault]] first; you may not need a plugin at all)

## The rule

One plugin per pain point, installed *after* you feel the pain. A plugin installed speculatively is clutter with a settings page.
